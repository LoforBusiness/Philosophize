# Profile backgrounds — drop the 10 images in THIS folder

Any filename, any format (PNG / JPG / WEBP). I'll rename, resize and register them.

Order matters only for one of them: **the woodcut cloud engraving (the cream one with
black line-shaded clouds) is the default** for every new user, so if you can, name that
one `03-clouds.*`. Everything else I can sort out from the picture.

## What each image is used for

One pick sets **both** the user's profile picture and their profile-header background,
so each image needs to work at two sizes:

- **Avatar** — a small circle, ~72px. Whatever is in the centre is all that survives.
- **Header background** — full width behind the name, rank and featured quote.

## Requirements

- **Landscape-ish or square**, at least ~1200px on the long edge. The header is wide and
  short, so tall portrait images get cropped hard top and bottom.
- Keep the **middle band calm**. The name, rank chip and quote sit across the centre —
  an image with its busiest detail there will fight the text no matter how I scrim it.
- B&W / ink / engraving reads best; that is the app's identity.

## Sourcing — READ THIS

Same rule as `assets/backgrounds/README.md`: **only images you have the rights to.**
Your own work, CC0 / public-domain (Openverse filtered to CC0, Wikimedia PD, rawpixel
public domain), or AI-generated. The app ships on Google Play, so anything scraped from
Pinterest / ArtStation / a comic is a real liability, not a theoretical one.

Every file added here must get a line in `CREDITS.txt` next to it, the same way
`assets/story/existence/CREDITS.txt` does it — source + licence + URL.
